# 미확인·추가 점검 항목

- **상태**: 미확인

아직 충분히 검증하지 않았거나, 사용자 피드백이 필요한 항목입니다.

## Undo / Redo (`Ctrl+Z`, `Ctrl+Y`)

- 물리키 조합 전환 후 기본 `EDIT` undo/redo에 맡기는 부분이 있다.
- 기본 EDIT는 1단계 undo라서 조합 중에는 Ctrl+Z가 마지막 자모 변경만 되돌린다.
- 커스텀 undo 스택은 `InputController`에 두면 Wrap 토글로 EDIT를 다시 만들어도 유지할 수 있다. 시나리오 테스트(`tests/editor_cases.txt`)로 검증 가능. 별도 작업으로 미결정.

## `Ctrl+Backspace` 동작

- 조합 중 key-step 되돌림, 비조합 단어 단위 삭제, 구두점 경계, 이모지(서로게이트) 앞 삭제 → 에디터 시나리오 테스트로 자동 검증 (해결).

## 조합 경계 시나리오

- 붙여넣기 직후, 방향키 이동 후, 마우스 클릭 후, 선택 영역 위 입력 → 에디터 시나리오 테스트로 자동 검증 (해결).
- 우클릭 메뉴의 "붙여넣기"는 `WM_RBUTTONDOWN`에서 조합을 확정하는 경로라 테스트의 `{Paste:...}`(Ctrl+V)와 다르다. 실제 앱에서 수동 확인 필요.

## 고배율 DPI

- PerMonitorV2로 바꿨지만 개발 PC는 100%다. 125%/150% 모니터에서 상단바·거터·아이콘 선명도, 모니터 간 이동(`WM_DPICHANGED`)을 실기로 확인해야 한다.

## SmartScreen

- 포터블 exe 배포 시 Windows SmartScreen 경고 가능성.
- 코드 서명·배포 채널 정책은 별도 검토.
